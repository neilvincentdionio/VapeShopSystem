Place the generated mobile APK in this folder and name it:

QuickPuffMobile.apk

Download links in the web app currently point to:
/downloads/QuickPuffMobile.apk

How to generate (Run in Android Studio does NOT create this file):
1. Double-click VapeShopMobile/build-apk.bat
   OR Build > Build Bundle(s) / APK(s) > Build APK(s)
2. Output: VapeShopMobile/app/build/outputs/apk/debug/app-debug.apk
3. build-apk.bat copies it here automatically as QuickPuffMobile.apk
